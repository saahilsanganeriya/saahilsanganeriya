Hi, I'm Saahil. I'm a software engineer on Mercor's Applied AI team in San Francisco, building the systems that
anonymize company data before it is used to train AI. Before that I did data engineering at Amazon and Coca-Cola, and
research on cell segmentation at Georgia Tech, where I studied computer science.

I mostly build backend and data systems in Go and Python, and lately environments and tools for testing AI agents.

**Projects**

- [Entity resolution and anonymization](https://saahilsanganeriya.com/projects/entity-resolution-and-anonymization)
  at Mercor: works out which names, emails and handles belong to the same person, then gives each person one
  consistent fake identity.
- [swe-sim](https://github.com/saahilsanganeriya/swe-sim): turns real GitHub issues into graded coding-agent tasks,
  with a simulated stakeholder the agent can question before it writes a patch.
- [travel-agent-gym](https://github.com/saahilsanganeriya/travel-agent-gym): a Gymnasium environment where an agent
  interviews a client, books the trip, then deals with what goes wrong.
- [saahil-brain](https://github.com/saahilsanganeriya/saahil-brain): one folder of notes, the same on two machines,
  that every coding-agent session reads from.
- [SAMCell](https://github.com/saahilsanganeriya/SAMCell): Segment Anything fine-tuned to outline every cell in a
  microscope image, published in [PLOS ONE](https://doi.org/10.1371/journal.pone.0319532).
- [real_time_streaming](https://github.com/saahilsanganeriya/real_time_streaming): the Apache Flink pipeline I built
  at Amazon to replace an hourly batch job.
- [projectionist](https://github.com/saahilsanganeriya/projectionist): one Go service that runs my film library on a
  NAS and pauses heavy jobs while someone is watching.
- [referral-network](https://github.com/saahilsanganeriya/referral-network): a small Python library for referral
  graphs: who referred whom, each person's reach, and the people most paths run through.

The write-ups for these, and more, are on [saahilsanganeriya.com](https://saahilsanganeriya.com).
